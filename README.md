## AI Chatbot Setup

Copy `.env.example` to `.env.local` and add an OpenAI API key to `OPENAI_API_KEY`. The key is read only by the server-side `/api/chat` route; do not commit `.env.local` or expose the key with a `NEXT_PUBLIC_` variable. `OPENAI_MODEL` is optional and defaults to `gpt-4.1-mini`.

For Vercel, add `OPENAI_API_KEY` (and optionally `OPENAI_MODEL`) under Project Settings → Environment Variables, then redeploy. Without a key, the chat switches to a clearly labeled portfolio-only demo mode; it does not pretend those replies were generated by AI. The static offline export (`npm run build:offline`) has no server runtime, so chat replies are available only in the normal server build.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
