Zyrus Portfolio - Offline Website

Open index.html in a browser to view the portfolio without a web server.
Keep all files and folders in this package together. The case study opens from case-study.html.

The site itself works offline. Social profile links require an internet connection, and the contact form is a frontend demo that does not send messages.

To add the profile photo, place it at images/profile/zyrus-portrait.jpg before rebuilding the offline export.
